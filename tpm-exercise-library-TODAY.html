⚙ GITHUB IMAGE SETTINGS
When a GitHub token is set, exercise images you upload are automatically saved to your tpm-workouts GitHub repo and will work on every device — not just this browser. Exercise data (exercises.json) also syncs automatically whenever you save or delete an exercise.
To get your token (takes ~2 minutes):
1. Go to github.com → Settings → Developer settings
2. Click Personal access tokens → Fine-grained tokens
3. Click Generate new token
4. Under Repository access, select Only select repositories → pick tpm-workouts
5. Under Permissions → Repository permissions → Contents, choose Read and write
6. Click Generate token and copy it here
Your token is stored only in this browser. Clear the field and save to remove it.
Get a free token at app.bitly.com → Settings → API. Clear and save to remove.
