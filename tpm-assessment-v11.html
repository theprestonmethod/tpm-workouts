5B
CIM Neuromotor Screen
Cognition in Motion™ — proprietary neuromotor baseline · all TPM clients
CIM OVERLAY — These five tests form the neuromotor baseline for all TPM clients. Results repeat at re-assessment for direct comparison. All scored results flow to Google Sheets automatically.
Test 1 — Single Leg Balance with Dual Task

Client balances on one leg while performing a simultaneous cognitive task. Record seconds to balance break. Dual Task Cost % auto-calculates using the standard SLB scores from Section 4.

Test 2 — Tennis Ball Wall Throw

Client throws and catches against wall from a fixed distance. Tests reactive motor sequencing and hand-eye coordination.

Test 3 — Movement Sequence Learning

Coach demonstrates a sequence of movements. Client repeats from memory. Tests motor learning and sequential pattern acquisition.

Test 4 — Movement Memory

Coach teaches 3–4 movements, pauses 2–3 minutes (client performs a different task), then asks for recall. Tests motor memory consolidation.

0 = no recall  ·  1 = partial  ·  2 = full with cueing  ·  3 = full independent

Test 5 — Short-Term Recall Under Load

Client given a short list of items to remember, then performs a physical task. Coach asks for recall immediately after. Tests working memory under physical stress.
